# Phase-1 benchmark inputs

The input data for the gene-cluster classification benchmark: the clusters and
genes to classify, their phenotypic features, the per-screen context, and the raw
expert annotations. Scoring/benchmarking is layered on top of this data elsewhere.

## Files

- **`benchmark_input.csv`** — the master table, one row per `(screen, cluster, gene)`:
  - `screen_name, cluster_id, role, gene_symbol, up_features, down_features, phenotypic_strength`
  - `role` ∈ `scored` (evaluated clusters), `abstain` (a real cluster with no coherent
    pathway), `decoy_shuffled` / `decoy_abstain` / `decoy_functional` (negative controls).
    Slices are filters on `role`, not separate files.
  - `up_features` / `down_features` — the gene's significant morphological features (knockout
    phenotype), `"; "`-joined, most-significant-first, split by direction of effect.
  - `phenotypic_strength` — magnitude of the perturbation phenotype vs non-targeting controls.

- **`ground_truth/annotation_{eric,liz,iain}.csv`** — the three experts' raw per-gene
  annotations (classification, subclass, nominated pathway, coherence, …). One file per reviewer.
- **`ground_truth/survey_key.csv`** — the annotation blinding key: per gene, which real
  source (`srcA_src` / `srcB_src` = uniprot/affinage) was shown as option A vs B, so the
  reviewers' blinded `preferred_source` (A/B) can be decoded.
- **`benchmark_ground_truth.csv`** — the three reviewer tables merged into one, with per-reviewer
  columns (`classification_eric`, `subclass_liz`, …). **Consensus-agnostic** — the raw labels are
  the ground truth; any consensus is computed downstream. Generated by `../merge_reviewers.py`.
- **`<screen>_screen_context.json`** — per-screen assay/imaging/clustering context (5 screens).

## Producers

- **`../merge_reviewers.py`** — `ground_truth/annotation_*.csv` → `benchmark_ground_truth.csv`.
- **`../build_bundles.py`** — `benchmark_input.csv` → `../benchmark_bundles/` (master superset bundles),
  one evidence bundle per cluster with the per-gene features plus UniProt/Affinage functional
  annotations (a thin wrapper over `mozzarellm.pipeline.bundle_builder`).

The per-gene feature columns are baked into `benchmark_input.csv` from the upstream screen
outputs as a one-off data-prep step (external, not run from this repo).
